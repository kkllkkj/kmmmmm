# 形象资产

所有毛绒图像均通过内置 image_gen 生成，采用用户参考图及已确认的正面形象，未使用 CLI。

- tiger-front.png：确认正面，上衣修正后的原始预览。
- tiger-views.png：侧面、背面、四分之三视角设定（未接入动画）。
- tiger-actions.png：六姿态原始预览。
- tiger-standing.png：透明正面站立。
- tiger-sprites.png：透明六姿态图，运行时按格裁切。
- tiger-focus.png：哑铃、书桌看书、电脑学习三姿态。
- tiger-workout.png：哑铃放下、抬起两个关键姿态。
- tiger-talents.png：持话筒唱歌、桌前写歌、跳舞（也用于 wink）。

提示词核心规范：保持确认形象的金黄色短绒毛、黑色圆耳和白耳毛、宽白脸颊、刺绣眼睛、蓝色无袖上衣、黄黑尾巴；透明背景，完整角色、相同身份和比例；动作图按等分单元排布。跑跳四足，睡觉蜷卧，学习坐在书桌前，锻炼手持两只哑铃，唱歌必须手持话筒。仅修改服装时保留其他特征。

这些是关键姿态资产，并非经过完整运动一致性约束的逐帧动画。图像原始生成文件仍保留在 Codex generated_images 目录中。
