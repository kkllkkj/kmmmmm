小虎陪伴 Windows 版 0.2.0

1. 先解压整个 ZIP 到一个文件夹。
2. 双击 TigerPet.exe。请保留同文件夹里的 DLL、resources、locales 等所有文件，不能只发送 EXE。
3. 点击小虎下方“任务”打开任务、食堂、复盘、陪伴记录和设置。
4. 拖动“拖动这里抱走小虎”区域移动；右键选择唱歌、写歌、跳舞、举哑铃或退出。
5. 点击小虎随机摸头、打招呼或 wink。唱歌有话筒，目前为姿态和台词，不输出声音。
6. 添加学习/锻炼任务，点击开始；可暂停、继续、结束。结束后显示时长；勾选完成任务才获得积分。
7. 食堂有 16 种食物和免费饭团，购买后投喂，增加亲密度。
8. 语录默认每 5 分钟触发，启动约 20 秒后首次尝试。安静、睡眠、专注时不主动说话，随时可点“语录”。
9. 数据保存在 %APPDATA%/tiger-pet-windows/data.json，退出自动保存。更换程序文件不会清空存档。
10. 本程序没有正式 Windows 发布者签名，也未在真实 Windows 电脑上完成界面验收。如 Windows 提示无法验证发布者，请确认来源和文件后由你自行决定是否运行。

支持 Windows 10/11 x64；不是 Windows ARM 专用包。
动画目前为关键姿态切换，非完整连续逐帧动画。食物使用系统 Emoji，部分图标是近似。Windows 暂未实现其他应用全屏自动检测，可手动开启安静陪伴。
